About This System

This Expense Manager is a full-stack web application built with modern technologies.

Featuring:

  • ✨ Flask Python Backend with SQLite Database
  • 🔐 Secure Authentication & Password Hashing
  • 📝 Comprehensive Activity Logging System
  • 🎨 Modern UI with Glassmorphism Design
  • 💫 Smooth Animations & Graphics
  • 📊 Advanced Filtering & Search
  • 💰 Budget Tracking & Monthly Summaries
  • 📤 CSV Export Functionality

Tech Stack: Flask, Python, SQLite, HTML5, CSS3, JavaScript
